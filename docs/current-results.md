# 현재 결과와 사용자 관점 평가

2026-10-07 기준. 커밋 전 변경사항과 현재 로컬 실행 결과를 검토했다.

## 확인한 결과

사용자 관점 평가 당시 실행 폴더 21개는 실제 조사 7개와 가짜 CLI 테스트 14개였다. 실제 조사는 응답 저장 3개, 실패 4개다. 이후 스모크 테스트 재실행으로 가짜 기록이 추가될 수 있다. 가짜 CLI 테스트의 성공·실패 기록은 오류 처리 검사를 위한 것이므로 조사 성공률에 포함하지 않는다.

- 실제 조사에서는 질문만 입력해 공식 문서 검색과 한국어 답변 저장까지 이어졌다.
- 접근할 수 없는 참고 주소를 포함한 재실행은 실패를 알린 뒤 공식 도메인에서 대체 검색을 계속하고 답변을 저장했다.
- 검토한 답변의 핵심 설명은 Python 공식 원문의 관련 절과 일치했다. 검증 범위는 TaskGroup과 gather에 관한 소수 질문이다.
- 기본 권한에서 CLI 초기화 오류가 발생했고, 권한 승인 후 실행은 완료됐다. 원인은 확정하지 않았다.
- 한 번은 사용량 한도로 중단됐다. 이후 동일 조건 재실행은 완료됐다.
- 최신 스모크 테스트 13개와 `git diff --check`가 통과했다. 스모크 테스트는 외부 서비스를 호출하지 않는다.

## 결과를 찾는 경험

폴더명은 이제 현지 날짜·시간, 질문 앞부분, 고유번호를 포함한다. 기존 15개 폴더도 한국 시각으로 이름을 변경했으며, 변경 전후 파일 해시가 같음을 확인했다. 원래 실행 ID와 파일 내용은 보존했다.

로컬 `runs/README.md`에서 질문, 실제 조사·가짜 테스트 구분, 상태, 답변 또는 실패 기록을 확인할 수 있다. 이 목록은 평가 당시 결과의 스냅샷이며 자동 갱신 기능은 아니다. `runs/`가 Git 제외 대상이므로 목록과 전체 실행 결과는 커밋에 포함되지 않는다. 공유용으로 선별한 [비교 답변](examples/taskgroup-vs-gather.md)과 [대체 문서 조사 답변](examples/taskgroup-alternative-document.md)은 질문과 검토 한계를 덧붙여 별도로 보존했다.

질문 앞부분을 제목으로 쓰므로 뒤쪽의 중요한 조건이 생략될 수 있다. 폴더명만으로 성공 여부를 알 수 없고, 테스트 결과도 같은 위치에 쌓인다. 이전 실행 ID로 된 채팅 링크는 폴더 이름 변경 후 사용할 수 없다. 실행 ID는 `run.json`과 실험 기록에 남아 추적할 수 있다.

## 개선 우선순위

1. **본문 열람 증거:** 열람 URL, 성공 여부, 근거 절을 독립적으로 확인할 수 있는 기록 방법을 검토한다. `other`를 열람 성공으로 임의 해석하지 않는다.
2. **결과 탐색:** 실제 조사와 가짜 테스트를 구분하고, 상태와 질문으로 찾아볼 수 있도록 실행 목록의 자동 갱신 또는 저장 위치 분리를 검토한다.
3. **답변 인용:** 결론과 한계의 기술적 주장까지 바로 뒤에 링크가 있는지 확인한다. 현재 응답 수신 상태인 `needs_review`를 내용 검증 성공으로 표시하지 않는다.
4. **실행 환경:** 초기화 오류와 사용량 중단을 사용자에게 더 명확히 안내하는 방법을 검토한다. 권한 승인 후 성공을 원인 해결로 기록하지 않는다.
5. **공유용 결과:** 실제 응답 두 개를 `docs/examples/`에 선별하고 질문·검토 범위를 추가했다. 향후 다른 기술 질문의 사례를 검증해 보완한다. 실행 로그 전체는 추적 대상에서 제외한다.

현재 버전은 질문부터 답변 저장까지의 동작과 일부 실패 처리를 확인한 기준점으로 커밋할 수 있다. 본문 열람의 독립 검증과 다양한 기술 질문의 품질 검증까지 완료한 버전으로 소개하기에는 근거가 부족하다.
