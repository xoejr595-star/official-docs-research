# Official Docs Search

입력은 기술 질문과 허용된 공식 문서 도메인 목록이다.
호스트는 사용자가 제공한 조사 범위이며 이 스킬이 공식성 자체를 인증하지는 않는다.

1. 질문에서 핵심 기술 용어를 추려 영문 검색어를 만든다. `site:도메인`을 포함하고 도구가 지원하면 도메인 필터도 적용한다.
2. 검색 결과에서 질문에 직접 답하는 문서를 선택한다. 검색 요약만으로 답변하지 말고 웹 열람 도구로 본문을 연다.
3. 최종 URL의 호스트가 허용 도메인 또는 그 하위 도메인인지 확인한다. 외부로 리디렉션된 문서는 근거에서 제외한다. `docs.python.org.example.com`은 `docs.python.org`가 아니다.
4. 질문과 관련된 절을 읽고, 해당 내용이 적용되는 버전을 확인한다.
5. 검색 결과가 질문과 맞지 않으면 기술 용어, 문서 절 제목, 버전으로 검색어를 구체화한다. 허용 도메인은 유지한다.
6. 본문 접근 실패, 관련 근거 없음, 서로 다른 버전은 명시한다. 검색 결과가 부족해도 비공식 출처를 섞지 않는다.

조사 결과로 문서별 제목, 최종 URL, 버전(확인 가능한 경우), 관련 절 제목과 근거 요지를 반환한다. 수집하지 못한 근거는 그 이유와 함께 남긴다.
